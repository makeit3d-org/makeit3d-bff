# MakeIt3D API Developer Guide

A powerful image processing API for background removal, upscaling, and downscaling operations.

## 🚀 Quick Start

### Base URL
```
https://api.makeit3d.io
```

### Authentication
All requests require an API key in the headers:
```bash
curl -H "X-API-Key: your_api_key_here" \
     https://api.makeit3d.io/generate/remove-background
```

## 📋 How Task IDs Work

The MakeIt3D API uses an **asynchronous task-based pattern** for all processing operations:

### 1. Submit Job → Get Task ID
When you call any generation endpoint, you immediately receive a `task_id`:

```bash
curl -X POST https://api.makeit3d.io/generate/remove-background \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "task_id": "my-unique-id-123",
    "provider": "stability", 
    "input_image_asset_url": "https://your-image-url.com/image.jpg"
  }'
```

**Response:**
```json
{
  "task_id": "my-unique-id-123"
}
```

### 2. Poll for Status → Track Progress
Use the returned `task_id` to check processing status:

```bash
curl https://api.makeit3d.io/tasks/my-unique-id-123/status \
  -H "X-API-Key: your_api_key"
```

**Response (Processing):**
```json
{
  "status": "processing",
  "progress": 75
}
```

**Response (Complete):**
```json
{
  "status": "complete", 
  "progress": 100,
  "asset_url": "https://storage-url.com/result.png"
}
```

### 3. Download Result → Get Final Asset
When `status` becomes `"complete"`, download your processed image from the `asset_url`.

## 🎯 Core Endpoints

### Remove Background

Remove backgrounds from images using AI.

**Endpoint:** `POST /generate/remove-background`

**Providers:** `stability`, `recraft`

```bash
curl -X POST https://api.makeit3d.io/generate/remove-background \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "stability",
    "input_image_asset_url": "https://example.com/photo.jpg",
    "output_format": "png"
  }'
```

**Response:**
```json
{
  "task_id": "remove-bg-1638360001-a1b2c3d4"
}
```

**Required Fields:**
- `provider` - AI provider (`"stability"` or `"recraft"`)
- `input_image_asset_url` - URL to the source image

**Note:** The `task_id` is automatically generated by the server and returned in the response.

### Upscale Image

Enhance image resolution and quality.

**Endpoint:** `POST /generate/upscale`

**Providers:** `stability`, `recraft`

```bash
curl -X POST https://api.makeit3d.io/generate/upscale \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "stability",
    "input_image_asset_url": "https://example.com/low-res.jpg",
    "model": "fast",
    "prompt": "high quality detailed image"
  }'
```

**Response:**
```json
{
  "task_id": "upscale-1638360002-e5f6g7h8"
}
```

**Required Fields:**
- `provider` - AI provider (`"stability"` or `"recraft"`)  
- `input_image_asset_url` - URL to the source image

**Note:** The `task_id` is automatically generated by the server and returned in the response.

### Downscale Image

Reduce file size while maintaining quality.

**Endpoint:** `POST /generate/downscale`

```bash
curl -X POST https://api.makeit3d.io/generate/downscale \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "input_image_asset_url": "https://example.com/large.jpg",
    "max_size_mb": 2.0,
    "aspect_ratio_mode": "original",
    "output_format": "jpeg"
  }'
```

**Response:**
```json
{
  "task_id": "downscale-1638360003-i9j0k1l2"
}
```

**Required Fields:**
- `input_image_asset_url` - URL to the source image
- `max_size_mb` - Target file size in megabytes

**Note:** The `task_id` is automatically generated by the server and returned in the response.

## 📊 Task Status Monitoring

**Endpoint:** `GET /tasks/{task_id}/status`

**Status Values:**
- `"processing"` - Job is in progress
- `"complete"` - Job finished successfully
- `"failed"` - Job encountered an error

**Example Polling Loop (JavaScript):**
```javascript
async function waitForCompletion(taskId) {
  while (true) {
    const response = await fetch(`https://api.makeit3d.io/tasks/${taskId}/status`, {
      headers: { 'X-API-Key': 'your_api_key' }
    });
    
    const status = await response.json();
    
    if (status.status === 'complete') {
      return status.asset_url; // Download URL ready
    }
    
    if (status.status === 'failed') {
      throw new Error('Processing failed');
    }
    
    // Wait 2 seconds before next check
    await new Promise(resolve => setTimeout(resolve, 2000));
  }
}
```

## 💾 Asset Storage & Expiration

### Storage Details
- **Generated assets** are stored in Supabase Storage
- **Private buckets** use signed URLs with **1 hour expiration**
- **Public buckets** provide permanent URLs (for test/demo content)

### Asset Lifecycle
1. **Upload**: Your input images are temporarily stored
2. **Processing**: AI providers generate processed versions  
3. **Storage**: Results are saved to secure storage
4. **Access**: You receive URLs to download results
5. **Expiration**: Private asset URLs expire after 1 hour

### Download Recommendations
- **Download immediately** when `status` becomes `"complete"`
- **Save to your own storage** for long-term access
- **Don't rely on asset URLs** beyond 1 hour for private buckets

## ⚡ Best Practices

### Task ID Management
Task IDs are **automatically generated by the server** using this format:
```
{operation}-{timestamp}-{random_id}

Examples:
- "remove-bg-1638360001-a1b2c3d4"
- "upscale-1638360002-e5f6g7h8"
- "downscale-1638360003-i9j0k1l2"
```

**You should never generate task IDs yourself.** Always use the task ID returned by the server.

### Efficient Polling
```bash
# Poll every 2-5 seconds (not too frequent)
# Implement exponential backoff for long operations
# Set reasonable timeouts (60-300 seconds depending on operation)
```

### Error Handling
```javascript
// Always handle the three status states
switch (status.status) {
  case 'processing':
    // Show progress, continue polling
    break;
  case 'complete': 
    // Download result from asset_url
    break;
  case 'failed':
    // Handle error, check status.error for details
    break;
}
```

## 📚 Complete Example

Here's a full workflow for removing a background using JavaScript:

```javascript
const API_KEY = 'makeit3d_test_sk_dev_001'; // Use your API key
const BASE_URL = 'https://api.makeit3d.io';

async function removeBackground(imageUrl) {
  try {
    // 1. Submit background removal job
    console.log('🚀 Submitting background removal job...');
    const submitResponse = await fetch(`${BASE_URL}/generate/remove-background`, {
      method: 'POST',
      headers: {
        'X-API-Key': API_KEY,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        provider: 'stability',
        input_image_asset_url: imageUrl,
        output_format: 'png'
      })
    });
    
    if (!submitResponse.ok) {
      throw new Error(`Submit failed: ${submitResponse.status}`);
    }
    
    const submitResult = await submitResponse.json();
    console.log(`✅ Job submitted with server-generated task ID: ${submitResult.task_id}`);
    
    // 2. Poll for completion
    console.log('⏳ Polling for completion...');
    const assetUrl = await pollForCompletion(submitResult.task_id);
    
    // 3. Download result (or return URL for client-side download)
    console.log(`🎉 Background removal complete!`);
    console.log(`📥 Download URL: ${assetUrl}`);
    
    return assetUrl;
    
  } catch (error) {
    console.error('❌ Error:', error.message);
    throw error;
  }
}

async function pollForCompletion(taskId, maxWaitTime = 180000) {
  const startTime = Date.now();
  const pollInterval = 2000; // 2 seconds
  
  while (Date.now() - startTime < maxWaitTime) {
    const response = await fetch(`${BASE_URL}/tasks/${taskId}/status`, {
      headers: { 'X-API-Key': API_KEY }
    });
    
    if (!response.ok) {
      throw new Error(`Status check failed: ${response.status}`);
    }
    
    const status = await response.json();
    console.log(`📊 Status: ${status.status}${status.progress ? ` (${status.progress}%)` : ''}`);
    
    switch (status.status) {
      case 'complete':
        return status.asset_url;
      case 'failed':
        throw new Error(`Processing failed: ${status.error || 'Unknown error'}`);
      case 'processing':
        // Continue polling
        await new Promise(resolve => setTimeout(resolve, pollInterval));
        break;
      default:
        throw new Error(`Unknown status: ${status.status}`);
    }
  }
  
  throw new Error(`Timeout: Processing took longer than ${maxWaitTime/1000} seconds`);
}

// Usage example
async function main() {
  try {
    const imageUrl = 'https://example.com/your-photo.jpg';
    const resultUrl = await removeBackground(imageUrl);
    
    // Result URL is ready for download
    console.log('🎯 Ready to download:', resultUrl);
    
  } catch (error) {
    console.error('💥 Failed:', error.message);
  }
}

// Run the example
main();
```
