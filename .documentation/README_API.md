# MakeIt3D API Developer Guide

A powerful image processing API for background removal, upscaling, and downscaling operations with **server-managed task IDs**.

## 🚀 Quick Start

### Base URL
```
https://api.makeit3d.io
```

### Authentication
All requests require an API key in the headers:
```bash
curl -H "X-API-Key: your_api_key_here" \
     https://api.makeit3d.io/generate/remove-background
```

## 📋 How Task IDs Work

The MakeIt3D API uses an **asynchronous task-based pattern** with **server-managed task IDs**:

### 1. Submit Job → Get Server-Generated Task ID
When you call any generation endpoint, the server automatically generates and returns a unique `task_id`:

```bash
curl -X POST https://api.makeit3d.io/generate/remove-background \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "stability", 
    "input_image_asset_url": "https://your-image-url.com/image.jpg"
  }'
```

**Response:**
```json
{
  "task_id": "remove-bg-1750625595-193ca577"
}
```

### 2. Poll for Status → Track Progress
Use the **server-generated task_id** to check processing status:

```bash
curl https://api.makeit3d.io/tasks/remove-bg-1750625595-193ca577/status \
  -H "X-API-Key: your_api_key"
```

**Response (Processing):**
```json
{
  "status": "processing",
  "progress": 75
}
```

**Response (Complete):**
```json
{
  "status": "complete", 
  "progress": 100,
  "asset_url": "https://storage-url.com/result.png"
}
```

### 3. Download Result → Get Final Asset
When `status` becomes `"complete"`, download your processed image from the `asset_url`.

### 🆕 What's New: Server-Managed Task IDs

**BREAKING CHANGE**: Clients no longer provide `task_id` in requests. The server now generates all task IDs automatically.

**Task ID Format:**
```
{operation}-{timestamp}-{uuid8}

Examples:
- "remove-bg-1750625595-193ca577"
- "upscale-1750625602-eb3f0bc8" 
- "downscale-1750625610-a1b2c3d4"
```

**Before (Old):**
```json
{
  "task_id": "my-unique-id-123",  // ❌ No longer accepted
  "provider": "stability",
  "input_image_asset_url": "https://..."
}
```

**Now (New):**
```json
{
  "provider": "stability",        // ✅ Required
  "input_image_asset_url": "https://..."  // ✅ Required
}
```

## 🎯 Core Endpoints

### Remove Background

Remove backgrounds from images using AI.

**Endpoint:** `POST /generate/remove-background`

**Providers:** `stability`, `recraft`

```bash
curl -X POST https://api.makeit3d.io/generate/remove-background \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "stability",
    "input_image_asset_url": "https://example.com/photo.jpg",
    "output_format": "png"
  }'
```

**Response:**
```json
{
  "task_id": "remove-bg-1750625595-193ca577"
}
```

**Required Fields:**
- `provider` - AI provider (`"stability"` or `"recraft"`)
- `input_image_asset_url` - URL to the source image

**Note:** The `task_id` is automatically generated by the server and returned in the response.

### Upscale Image

Enhance image resolution and quality.

**Endpoint:** `POST /generate/upscale`

**Providers:** `stability`, `recraft`

```bash
curl -X POST https://api.makeit3d.io/generate/upscale \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "stability",
    "input_image_asset_url": "https://example.com/low-res.jpg",
    "model": "fast",
    "prompt": "high quality detailed image"
  }'
```

**Response:**
```json
{
  "task_id": "upscale-1750625602-eb3f0bc8"
}
```

**Required Fields:**
- `provider` - AI provider (`"stability"` or `"recraft"`)  
- `input_image_asset_url` - URL to the source image

**Note:** The `task_id` is automatically generated by the server and returned in the response.

### Downscale Image

Reduce file size while maintaining quality.

**Endpoint:** `POST /generate/downscale`

```bash
curl -X POST https://api.makeit3d.io/generate/downscale \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "input_image_asset_url": "https://example.com/large.jpg",
    "max_size_mb": 2.0,
    "aspect_ratio_mode": "original",
    "output_format": "jpeg"
  }'
```

**Response:**
```json
{
  "task_id": "downscale-1750625610-a1b2c3d4"
}
```

**Required Fields:**
- `input_image_asset_url` - URL to the source image
- `max_size_mb` - Target file size in megabytes

**Note:** The `task_id` is automatically generated by the server and returned in the response.

## 📊 Task Status Monitoring

**Endpoint:** `GET /tasks/{task_id}/status`

**Status Values:**
- `"processing"` - Job is in progress
- `"complete"` - Job finished successfully
- `"failed"` - Job encountered an error

**Example Polling Loop (JavaScript):**
```javascript
async function waitForCompletion(taskId) {
  while (true) {
    const response = await fetch(`https://api.makeit3d.io/tasks/${taskId}/status`, {
      headers: { 'X-API-Key': 'your_api_key' }
    });
    
    const status = await response.json();
    
    if (status.status === 'complete') {
      return status.asset_url; // Download URL ready
    }
    
    if (status.status === 'failed') {
      throw new Error('Processing failed');
    }
    
    // Wait 2 seconds before next check
    await new Promise(resolve => setTimeout(resolve, 2000));
  }
}
```

## 💾 Asset Storage & Expiration

### Storage Details
- **Generated assets** are stored in Supabase Storage
- **Private buckets** use signed URLs with **1 hour expiration**
- **Public buckets** provide permanent URLs (for test/demo content)

### Asset Lifecycle
1. **Upload**: Your input images are temporarily stored
2. **Processing**: AI providers generate processed versions  
3. **Storage**: Results are saved to secure storage
4. **Access**: You receive URLs to download results
5. **Expiration**: Private asset URLs expire after 1 hour

### Download Recommendations
- **Download immediately** when `status` becomes `"complete"`
- **Save to your own storage** for long-term access
- **Don't rely on asset URLs** beyond 1 hour for private buckets

## 📚 Complete Example

Here's a full workflow for removing a background using JavaScript:

```javascript
const API_KEY = 'makeit3d_test_sk_dev_001'; // Use your API key
const BASE_URL = 'https://api.makeit3d.io';

async function removeBackground(imageUrl) {
  try {
    // 1. Submit background removal job (no task_id needed)
    console.log('🚀 Submitting background removal job...');
    const submitResponse = await fetch(`${BASE_URL}/generate/remove-background`, {
      method: 'POST',
      headers: {
        'X-API-Key': API_KEY,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        provider: 'stability',
        input_image_asset_url: imageUrl,
        output_format: 'png'
      })
    });
    
    if (!submitResponse.ok) {
      throw new Error(`Submit failed: ${submitResponse.status}`);
    }
    
    const submitResult = await submitResponse.json();
    console.log(`✅ Job submitted with server-generated task ID: ${submitResult.task_id}`);
    
    // 2. Poll for completion using server-generated task ID
    console.log('⏳ Polling for completion...');
    const assetUrl = await pollForCompletion(submitResult.task_id);
    
    // 3. Download result (or return URL for client-side download)
    console.log(`🎉 Background removal complete!`);
    console.log(`📥 Download URL: ${assetUrl}`);
    
    return assetUrl;
    
  } catch (error) {
    console.error('❌ Error:', error.message);
    throw error;
  }
}

async function pollForCompletion(taskId, maxWaitTime = 180000) {
  const startTime = Date.now();
  const pollInterval = 2000; // 2 seconds
  
  while (Date.now() - startTime < maxWaitTime) {
    const response = await fetch(`${BASE_URL}/tasks/${taskId}/status`, {
      headers: { 'X-API-Key': API_KEY }
    });
    
    if (!response.ok) {
      throw new Error(`Status check failed: ${response.status}`);
    }
    
    const status = await response.json();
    console.log(`📊 Status: ${status.status}${status.progress ? ` (${status.progress}%)` : ''}`);
    
    switch (status.status) {
      case 'complete':
        return status.asset_url;
      case 'failed':
        throw new Error(`Processing failed: ${status.error || 'Unknown error'}`);
      case 'processing':
        // Continue polling
        await new Promise(resolve => setTimeout(resolve, pollInterval));
        break;
      default:
        throw new Error(`Unknown status: ${status.status}`);
    }
  }
  
  throw new Error(`Timeout: Processing took longer than ${maxWaitTime/1000} seconds`);
}

// Usage example
async function main() {
  try {
    const imageUrl = 'https://example.com/your-photo.jpg';
    const resultUrl = await removeBackground(imageUrl);
    
    // Result URL is ready for download
    console.log('🎯 Ready to download:', resultUrl);
    
  } catch (error) {
    console.error('💥 Failed:', error.message);
  }
}

// Run the example
main();
```

## 🔄 Multi-Step Workflow Example

Here's a complete workflow that processes an image through multiple steps:

```javascript
const API_KEY = 'makeit3d_test_sk_dev_001';
const BASE_URL = 'https://api.makeit3d.io';

async function processImageWorkflow(originalImageUrl) {
  try {
    // Step 1: Remove background
    console.log('🔄 Step 1: Removing background...');
    const bgResponse = await fetch(`${BASE_URL}/generate/remove-background`, {
      method: 'POST',
      headers: {
        'X-API-Key': API_KEY,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        provider: 'stability',
        input_image_asset_url: originalImageUrl
      })
    });
    
    const { task_id: bgTaskId } = await bgResponse.json();
    const bgRemovedUrl = await pollForCompletion(bgTaskId);
    console.log(`✅ Background removed: ${bgTaskId}`);
    
    // Step 2: Upscale the result
    console.log('🔄 Step 2: Upscaling image...');
    const upscaleResponse = await fetch(`${BASE_URL}/generate/upscale`, {
      method: 'POST',
      headers: {
        'X-API-Key': API_KEY,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        provider: 'stability',
        input_image_asset_url: bgRemovedUrl
      })
    });
    
    const { task_id: upscaleTaskId } = await upscaleResponse.json();
    const upscaledUrl = await pollForCompletion(upscaleTaskId);
    console.log(`✅ Image upscaled: ${upscaleTaskId}`);
    
    // Step 3: Optimize file size
    console.log('🔄 Step 3: Optimizing file size...');
    const downscaleResponse = await fetch(`${BASE_URL}/generate/downscale`, {
      method: 'POST',
      headers: {
        'X-API-Key': API_KEY,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        input_image_asset_url: upscaledUrl,
        max_size_mb: 0.5,
        aspect_ratio_mode: 'original',
        output_format: 'png'
      })
    });
    
    const { task_id: downscaleTaskId } = await downscaleResponse.json();
    const finalUrl = await pollForCompletion(downscaleTaskId);
    console.log(`✅ File optimized: ${downscaleTaskId}`);
    
    return {
      original: originalImageUrl,
      backgroundRemoved: bgRemovedUrl,
      upscaled: upscaledUrl,
      final: finalUrl,
      taskIds: {
        background: bgTaskId,
        upscale: upscaleTaskId,
        downscale: downscaleTaskId
      }
    };
    
  } catch (error) {
    console.error('❌ Workflow failed:', error.message);
    throw error;
  }
}

// Helper function for polling (same as above)
async function pollForCompletion(taskId, maxWaitTime = 180000) {
  const startTime = Date.now();
  const pollInterval = 2000;
  
  while (Date.now() - startTime < maxWaitTime) {
    const response = await fetch(`${BASE_URL}/tasks/${taskId}/status`, {
      headers: { 'X-API-Key': API_KEY }
    });
    
    if (!response.ok) {
      throw new Error(`Status check failed: ${response.status}`);
    }
    
    const status = await response.json();
    
    switch (status.status) {
      case 'complete':
        return status.asset_url;
      case 'failed':
        throw new Error(`Processing failed: ${status.error || 'Unknown error'}`);
      case 'processing':
        await new Promise(resolve => setTimeout(resolve, pollInterval));
        break;
      default:
        throw new Error(`Unknown status: ${status.status}`);
    }
  }
  
  throw new Error(`Timeout: Processing took longer than ${maxWaitTime/1000} seconds`);
}

// Usage
async function runWorkflow() {
  try {
    const imageUrl = 'https://example.com/your-photo.jpg';
    const results = await processImageWorkflow(imageUrl);
    
    console.log('🎉 Complete workflow results:');
    console.log('📥 Original:', results.original);
    console.log('📥 Background Removed:', results.backgroundRemoved);
    console.log('📥 Upscaled:', results.upscaled);
    console.log('📥 Final Optimized:', results.final);
    console.log('🆔 Task IDs:', results.taskIds);
    
  } catch (error) {
    console.error('💥 Workflow failed:', error.message);
  }
}

runWorkflow();
```

## 🆕 Migration Guide

If you're upgrading from the previous version that required client-generated task IDs:

### What Changed
1. **Remove `task_id` from request bodies** - The server now generates them
2. **Use server-generated task IDs** for status polling
3. **Simplified request format** - Cleaner JSON without task_id field

### Migration Steps
1. **Update request bodies**: Remove any `task_id` fields from your API calls
2. **Update response handling**: Extract `task_id` from the response instead of using your own
3. **Update status polling**: Use the server-provided task ID for polling
4. **Test thoroughly**: Verify all workflows work with the new task ID system

### Example Migration

**Before:**
```javascript
// Old way - DON'T do this anymore
const myTaskId = `bg-remove-${Date.now()}`;
const response = await fetch('/generate/remove-background', {
  method: 'POST',

    task_id: myTaskId,  // ❌ Remove this
    provider: 'stability',

// Then poll with myTaskId
```

**After:**
```javascript
// New way - Server manages task IDs
const response = await fetch('/generate/remove-background', {
  method: 'POST',

    // ✅ No task_id field needed

    input_image_asset_url: imageUrl
```

The new system ensures better reliability, eliminates task ID conflicts, and provides a cleaner API experience.
